# 图纸类型识别

SKILL.md 第 2 节开始读图时用。判断四个维度，每个维度决定后面走哪条路。

## 1. 文件格式

| 格式 | 怎么认 | 后续 |
|---|---|---|
| vector_pdf | PDF 里能选中文字；preprocess 提取到大量线段和文字 | 尺寸用提取结果，置信度可到 0.95+ |
| dwg | .dwg 文件 | 自动转成 DXF 再读（scripts/dwg2dxf.py），和 dxf 一样准。**有 DWG 就优先用 DWG** |
| dxf | .dxf 文件 | 尺寸实体直接读显示值，圆心直径是精确值，最准 |
| raster | 扫描件、照片、截图；PDF 里只有一张图片 | 只能看图，置信度上限 0.85，必须人工确认全部尺寸 |

准确度：DWG = DXF > 矢量 PDF > 扫描图。同一个零件有多种格式时，用最准的那个。

DWG 转换顺序：ODA File Converter → 本机 CAD（AutoCAD / 中望 / 浩辰，和原图一样准）→ SolidWorks 导入再另存（最不准）。都不行时请用户在 CAD 软件里另存为 DXF。转换结果里的 `converted_from` 写明用了哪种。

读 DXF 时注意：
- 尺寸以 `displayed_text`（图上实际显示的文字）为准。`override_replaces_value: true` 表示标注被手改过，要和几何核对。
- 视图按比例画时尺寸带 DIMLFAC，`measurement` 是图上长度，`value_shown` 才是真实尺寸。
- `circles` 里是精确的圆心和直径，孔位直接用它算，比读尺寸链更准。
- `layers[].looks_like` 标出中心线、虚线图层，用来找回转轴和不可见轮廓。
- `image` 是渲染图，用来看视图关系。

## 2. 零件类型

| 类型 | 特征 | 支持 |
|---|---|---|
| revolved | 轴、套、法兰、盘、销。主视图上有中心线，尺寸多为 Ø | ✅ |
| prismatic | 板、块、支架、底座。尺寸多为长宽高，孔用坐标定位 | ✅ |
| 钣金 | 有展开图、折弯线、"K 因子"、板厚统一 | ❌ |
| 铸件、锻件 | 大量拔模、不规则圆角、"未注圆角 R3" | ❌（后续） |
| 曲面件 | 样条曲线、曲面造型 | ❌ |
| 装配图 | 有明细表、序号气泡 | ❌，请用户给零件图 |

一个零件同时像两类时（例如带方法兰的轴），按主体选，另一部分用切除特征补。拿不准就问用户。

## 3. 投影法

- 标题栏附近有投影符号（截头圆锥）。符号的位置关系决定是第一角还是第三角。
- 中国 GB、欧洲 ISO 图纸默认第一角；美国 ANSI 默认第三角。
- 判断方法和视图位置见 `projection.md`。

## 4. 视图组成

列出图上所有视图：主视图、俯视图、左视图、剖视图（A-A）、局部放大（I）、向视图。

- 剖视图最容易读错：剖面线区域是实体，空白是孔或空腔。
- 局部放大图的比例单独标注，尺寸以标注数值为准，不按比例量。
