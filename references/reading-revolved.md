# 回转类零件读图（轴、套、法兰、盘）

## 读图顺序

1. **找轴线**：主视图上的点画线（中心线）。轴类零件通常水平画。
2. **列外轮廓台阶**：沿轴线从一端到另一端，记下每一段的直径和长度。Ø 尺寸是直径，r 取一半。
3. **列内孔台阶**：剖视图（或虚线）里的内孔，同样记直径和长度。
4. **画 half_profile**：外轮廓从 (0, 0) 出发，沿 h 方向走完，再沿内孔回来。没有中心通孔时，轮廓的一边就在 r = 0 上。
5. **再加其他特征**：端面螺栓孔、键槽、径向孔、倒角。

## half_profile 示例

一根三段轴：Ø30×20，Ø40×50，Ø30×20，总长 90，无内孔：

```json
"half_profile": [[0,0],[15,0],[15,20],[20,20],[20,70],[15,70],[15,90],[0,90]]
```

带 Ø20 通孔的法兰（Ø100×15 盘 + Ø50×30 颈）：

```json
"half_profile": [[10,0],[50,0],[50,15],[25,15],[25,45],[10,45]]
```

## 规则

- 长度链要闭合：各段长度之和必须等于总长。不等时以总长和单独标注的段长为准，把冲突写进 open_questions。
- 直径相同的相邻段要合并成一段，不要出现长度为 0 的台阶。
- 图上的倒角（C1、1×45°）不要画进 half_profile，单独用 edge_treatment，或者按 reading-rules.md 的规则处理。
- 退刀槽、越程槽：MVP 阶段直接画进 half_profile（就是一个窄的凹台阶）。

## 端面螺栓孔

"4×Ø9 均布 PCD 80"：

```json
{ "id": "bolt_holes", "type": "hole", "plane": "top", "offset": 0, "diameter": 9,
  "bolt_circle": { "pcd": 80, "count": 4, "start_angle": 45 },
  "depth": "through_all", "direction": "both",
  "meta": { "confidence": 0.9, "evidence": "左视图 4×Ø9 EQS，PCD80；起始角按视图判断为 45°", "needs_review": true } }
```

起始角图上常常不标。不标时一般是 0° 或 45°，按视图判断，并置 needs_review。

## 键槽只写了键的规格

图上标了槽宽和 d + t2（或 d − t1）就照图建。只写"键 16×10 GB/T 1096"或只标了槽宽时，用 `python scripts/standards.py key <轴径>` 查 GB/T 1095：轴上槽深 t1、轮毂槽深 t2。

例：孔 Ø56，查表 d + t2 = 60.3，但图上标的是 61 (0/−0.2)。**以图纸为准，填 61。** 查表只补图上没写的数。

## 齿轮

渐开线直齿圆柱齿轮用 `spur_gear_teeth`，切在 `base_revolve` 轮坯上。

1. **齿形参数只从参数表读**：齿数 z、模数 m（法向模数）、压力角 α（齿形角）、齿顶高系数 ha*、顶隙系数 c*、变位系数 x。表一般在图纸右上角，DWG 里常是 ACAD_TABLE，preprocess 会解析到 `setup_hints.gear`。
2. **图上不画齿**（国标规定画法）：三个同心圆分别是齿顶圆（粗实线）、分度圆（点画线）、齿根圆（细实线）。主视图里对应齿顶线、分度线、齿根线。
3. **轮坯外径 = 齿顶圆 da**。half_profile 的最大 r 要等于 da/2，校验脚本会查。
4. **核对**：d = mz 应等于分度圆直径，da = m(z + 2ha* + 2x)，df = m(z − 2ha* − 2c* + 2x)。对得上，单位和参数就都对了。
5. 精度等级（8-8-7GK）写进 `accuracy`，只记录。
6. 斜齿轮（参数表有螺旋角 β）、内齿轮、锥齿轮当前不支持，按 SKILL.md 原则 3 停下。

```json
{ "id": "teeth", "type": "spur_gear_teeth", "module": 4, "teeth": 60, "pressure_angle": 20,
  "addendum_coef": 1, "clearance_coef": 0.25, "shift_coef": 0, "accuracy": "8-8-7GK",
  "meta": { "confidence": 0.97, "evidence": "参数表 z=60, m=4, α=20°；d=240 与分度圆 Ø240 一致" } }
```
