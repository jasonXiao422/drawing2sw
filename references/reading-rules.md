# 读图和填表规则

每条都是真实图纸上读错过一次才写下的。第 3 步之前从头扫一遍；拿不准时用 `scripts/search_refs.py` 按关键词搜。

格式：**规则**，然后是"怎么从图上看出来"或一个简短例子。

## 一、单位、标准、公差

### R1. 图上没写单位，要有依据
国内很多图默认 mm 不写。依据按可靠程度：标题栏或技术要求里的原文 > DXF 文件头 `$INSUNITS` / `$MEASUREMENT` > 齿轮 m·z 和分度圆核对 > "中文 + Ø + 配合代号"这类推断。只有推断时置信度不超过 0.85，并请用户确认。单位错了整个零件就错了。

### R2. 英寸图的数字写法
`.375`、`1/4`、`2-1/2`、德文图的逗号小数点 `12,5` 都是合法尺寸。自己看图读数时别漏掉这些写法。

### R3. 公差只用公称尺寸
`61 0/-0.2`、`Φ25H7` 一律按公称尺寸 61、25 建模，公差和配合代号写进 evidence。极限尺寸只给上下限（`Ø31.82-31.75`、上下叠写的 `1.4590/1.4585`），取中间值，callouts.py 会算好。

## 二、预处理结果怎么用

### R4. PDF 里的 Ø 可能丢了
CAD 导出的 PDF 常用专用字体画 Ø，文字层里会丢掉或变成 `n`、`P`、`%%c`、`∅`。同一张图里 `P3`、`P5` 这类字母加数字反复出现、又正好标在圆上时，就是 Ø3、Ø5。提取出的"线性尺寸"要回到页面图片核对前缀：在圆形视图里、或者引线指向圆的，按直径处理。

### R5. DXF 尺寸以显示文字为准
尺寸以 `displayed_text` 为准，不以几何测量值为准（视图可能按比例画，或者标注被手改过）。`override_replaces_value` 为 true 时，标注被手改过，要和几何核对并问用户。

### R6. 只有线条、没有文字层的矢量 PDF
AutoCAD 用 SHX 字体打印时文字变成线条（预处理标为 `vector_pdf_notext`）。几何精确，但数字要看图读，置信度上限 0.9，读出的数用线条长度按比例核对。

### R7. 齿轮
齿形参数只从参数表读（预处理会读出 ACAD_TABLE 表格）。国标规定画法不画齿形：三个同心圆是齿顶圆（粗实线）、分度圆（点画线）、齿根圆（细实线），用 d = m·z、da、df 核对，不要去量齿形。

## 三、视图和方向

### R8. 宽相等：左视图、俯视图的方位最容易错
左视图的水平方向、俯视图的竖直方向，都是零件前后方向（Z），不是左右。第一角投影里，这两个视图中靠近主视图的一侧是零件后面（−Z），远离的一侧是前面（+Z）；第三角相反。键槽、径向孔转了 90° 或者镜像了，体积完全不变，校验发现不了。方位定好后回主视图核对：特征在剖切面上就在剖面里可见，不在就只是投影线。确认环节请用户看这些方位。

### R9. 曲面至少在两个视图里核对
一个视图里是圆弧，另一个视图里是直线，就是圆柱面（轴线垂直于画弧的那个视图）；两个视图里都是弧才可能是球面。

### R10. 剖视图里被线围住、却没有剖面线的区域，多半是肋
GB 规定肋板、轮辐、薄壁被纵向剖切时不画剖面线，只用粗实线和相邻部分分开。先对照其他视图（截面视图里的 H 形、T 形，侧视图里的肋厚）判断是不是肋，不要直接当空腔切掉。

### R11. 侧视图、局部放大里的尺寸，参照点取那个视图里看得到的轮廓线
例：局部放大图里"低 3"，量在侧视图里圆柱的轮廓线（最外母线 x = R）上，不是量在三维里筋和圆柱的交线上。

### R12. 剖切符号说明剖到哪里
旋转剖、阶梯剖的剖切线会拐弯：剖视图的上半部分和下半部分可能是不同位置的切面（例如一半过 45° 方向的螺孔，一半过中心面）。读剖视图前先在其他视图里找到剖切线，弄清每一段切在哪。

### R33. 先认出剖视图是哪一种
- 全剖：整个视图切开。剖面线区域是实体，空白是孔、槽、空腔。
- 半剖：对称件一半画剖面、一半画外形，以中心线分界。剖开的那一半不画虚线，没剖的那一半也省略内部虚线，内部结构按对称补到另一半。
- 局部剖：用波浪线圈出一小块切开，只说明这一小块的内部（常见于孔、键槽）。
- 移出剖面：画在视图外面，标"SECTION A-A"或"A-A"，只表示剖切线那个位置的截面形状。臂、轮辐、弯管常用。
- 重合剖面：截面轮廓直接画在视图上（细实线），表示那个位置的截面，比如摇臂、轮辐上画的矩形、工字形。
- 斜剖、旋转剖、阶梯剖：剖切线是斜的、绕中心转的或拐弯的（见 R12）。剖视图里的长度是沿剖切线展开的，不是视图上的投影长度。

剖切线箭头指的是看的方向，剖视图画的是箭头那一侧的部分。

### R34. 移出剖面和重合剖面说明截面沿一条路径
截面不变、路径是曲线（S 形臂、90° 弯头）时，是扫描特征。特征表目前不支持扫描，报告能力缺口；路径由直线段和圆弧组成、截面是矩形或圆时，可以说明后用 revolve（圆弧段）加 extrude（直线段）拼出来，并在 evidence 里写清楚是拼接。

### R35. 不同视图的比例可能不同
"DETAIL A (2:1)"、"A (4:1)"、"TOP VIEW (shown scaled down)"：这个视图单独缩放过。上面的尺寸数字仍是真实尺寸；按比例量没标的结构时，只用同一个视图里的已知尺寸校准，不要拿别的视图的像素比例。

### R36. 文字写的几何关系照样要满足
"DIAMETER DETERMINED BY LOCATION"、"CENTERED IN BLOCK"、"COINCIDENT TO BOTH CORNERS"、"SLOT // TO EDGE"、"TANGENT"、"IN LINE"、只写 R 不写数：这些是约束，不是漏标。用 path 的 intersect、tangent_loop、对称位置去表达，必要时用 geom2d 算出数值，并把原文写进 evidence。不要随便填一个看起来合适的数。

### R37. 画了分布圆，孔不一定均布
只有写了 EQS、EQUALLY SPACED、均布，或者各孔角度相等时才均布。图上另外标了角度、偏距（例如几个孔到中心线的距离 12、12）时，按标注定位，用 positions 写每个孔，不用 bolt_circle 的等分。

### R38. 总注作用于所有没标的边
"ALL CHAMFERS = 0.5 X 45°"、"FILLETS AND ROUNDS R3"、"未注倒角 C1"、"未注圆角 R2"：图上没单独标注的棱边、内外角都按它处理。铸件的未注圆角很多，会明显影响体积和表面积；特征表一次表达不了的，说明按总注做了哪些、漏了哪些。"2 REQD"、"C I"、"CAST STEEL" 是件数和材料，和几何无关。

### R40. 剖视图的上下左右要用特征去对
剖视图常被旋转或翻转后摆放，不能默认剖视图上方就是零件顶面。找一个两边都有的特征去对：俯视图上的槽宽、腔的范围、孔的位置，在剖视图里落在哪一侧、多宽、多深。对上了再读其余结构。读反了整个零件会上下颠倒，体积不变，校验查不出来。

### R41. 一个圆一半实线、一半虚线
从这一面看过去，实线那半看得见，虚线那半被挡住。典型情况是从背面钻的孔打穿了正面的腔：腔里能看见孔口（实线），腔外被顶面挡住（虚线）。两边深度加起来正好等于厚度时，就是在那个平面上打通；剖视图里两段空白之间那条线只是边界，不代表还有材料。

### R39. 练习图里的提示图、步骤图不是零件视图
"HINT"、"STEP 1"、"FINAL" 这类小图是出题人的提示或建模步骤，不按投影关系读。它们可以帮你理解建模顺序，但尺寸以正式视图为准。

## 四、尺寸从哪量起

### R13. 同心圆之间的小尺寸，先看箭头落在哪两个圆上
例：三个同心圆，小尺寸 6 标在凸台和孔之间，就是壁厚，从孔量起：凸台 = Φ孔 + 2×6。拿不准时两种都算，用题目给的体积或面积挑。

### R14. 一个孔周围有几圈圆，就有几级台阶
每一圈的直径和深度分别找标注。标 R 的那一圈常常和外形圆角同心（沉平面），标 Φ 的是沉孔。

### R15. 看着对称，也要每处单独读
上下两个圆角一个标 R4、一个标 R6 很常见。没有对称符号或"2×"时，不要按对称补尺寸。

### R16. 专门放大、标注的点就是构造点
图上专门放大"交点""切点"的地方，轮廓在那里拐弯或相切。用 `intersect` 写这个点，不要当成相切。

### R17. 没标的尺寸不要编
图上找不到的尺寸写进 `open_questions`。量图估出来的数可以先用，但要写"量图约 X"，置信度不超过 0.75，并请用户确认。图太模糊、数字认不清时，先请用户给更清楚的图。

### R26. 孔、槽、倒角标注先交给 callouts.py 解析
`2X ⌀4.5 THRU ⌴⌀7 ↧3.5`、`4×Φ9 沉孔Φ15深5`、`4X ⌀5 EQ SP ON ⌀60 B.C.` 这类标注不要自己拆。运行 `scripts/callouts.py "原文"`，输出里的 feature_hint 可以直接用作 hole 特征的 diameter、depth、cbore、csink、bolt_circle。符号：⌴（也写成 ⊔、L_J、CBORE）沉孔，⌴ … SF 锪平，⌵（也写成 ∨、CSK）沉头，↧（也写成 ▼、DEEP、深）深度，EQS / EQ SP / EQUALLY SPACED / 均布 等分，B.C. / BC / PCD 分布圆，(2X5) 两行五列，3 PLCS / 3 处 是数量，IN LINE 同轴。英制螺纹 `1/2-13 UNC - 2B`、`#10-32 UNF` 也能解析。返回 unknown 的写法说明规则没覆盖，看图判断并记下原文。

### R27. 孔标注没写 THRU，也没写深度
ISO 图常省略 THRU。深度去别的视图找：侧视图或剖视图里孔的虚线、剖面线从哪到哪。虚线贯穿整个厚度就是通孔，停在中间就是盲孔，再找深度尺寸。几个视图都看不出来就写进 open_questions，不要默认通孔。

### R28. 单独的 ⌀ 不一定是孔
`⌀80` 可能是孔径，也可能是轴、凸台、法兰的外径。看它标在哪个视图、尺寸线两端落在实线外轮廓上，还是落在虚线或剖面里的内轮廓上。带数量、THRU、深度、沉孔符号的才肯定是孔。

### R29. 这些标注不进特征表
形位公差框（平面度、垂直度、位置度等）、基准符号（方框里的 A、B）、表面粗糙度，不改变公称几何，不写尺寸，写进 evidence 即可。括号里的参考尺寸 `(35)` 可以由别的尺寸推出，只用来核对，不当作建模依据。这些在尺寸归属检查里不会被当成"没被引用的尺寸"。

### R30. 高度标注 H 12
有的图在俯视图里用 `H 12` 标某个面的高度（相对零件底面或标注的基准）。它对应主视图或侧视图里那个台阶、凸台的高度尺寸，两边要一致。

### R31. 数值对得上，不等于找对了被标的面
一个尺寸量的是哪两个面，要看它两条界线（或箭头）落在哪里，在视图上量出这两处的位置去核对，不要因为某个特征刚好也是这个数就认定是它。尤其是高度：总高减去某段高度，常常碰巧等于另一个尺寸。图上有没解释的虚线（隐藏的台阶、空腔底面），先看有没有尺寸正好标到它；有，就说明这个尺寸属于那个隐藏结构。

### R32. 没标尺寸的结构，按比例量要有校准
图纸欠标注、又必须先出模型时，用图上已标的两个尺寸校准像素比例（不要只信标题栏的比例），再量没标的结构，取整到常见值（整数或 0.5）。量出的值置信度按 R17 的上限，写进 open_questions，并在 evidence 里写"按比例量"。推出来的尺寸（例如带圆角的六边形，对角距 = 对边 / cos30° − 圆角修正）要能和图上标的尺寸互相印证。

## 五、写特征表

### R18. 切点、圆心、交点不要手算
拐角倒圆写 `fillet`，几个圆用切线连写 `tangent_loop`，交点写 `intersect`，只知道半径的圆弧写 `radius`，沉孔 / 埋头孔 / 钻尖写在 hole 的 `cbore` / `csink` / `tip_angle` 里（feature-table.md "v0.4 新增"）。手算容易算错，四舍五入后又不严格相切，SolidWorks 的圆角会在接缝上失败。这些写法都覆盖不到时用 `scripts/geom2d.py` 算，抄 6 位小数。

### R19. path 的起点放在拐角上
起点放在一段圆弧中间，会把弧拆成两段。v0.4 写法脚本会自动合并，手写 v0.3 path 时要自己注意。

### R20. 重复的特征写成一组
均布孔用 `bolt_circle`，同直径的孔放进一个 hole 的 `positions`，不要拆成很多个特征。

### R21. 切到圆柱曲面为止
拉伸只能切到平面。槽底是圆柱面时：先切到曲面最深处，再用 extrude 把曲面外侧补回来（feature-table.md "切到曲面为止"）。

### R22. 外形里重叠一点没关系
加料特征伸进已有实体内部是允许的（并集）。例如支撑墙的轮廓直接画到圆筒轴线，不用精确算出和圆筒表面的交线。但切除特征不能和已有的面重合。

## 六、核对结果

### R23. 能对答案就一定对
题目给了体积、某个面的面积、两点距离（CATICS 这类题），先在 CadQuery 预览里全部对上再进 SolidWorks。面积和距离能定位是哪个尺寸读错了，比只看体积有用。

### R24. 有答案模型时，用它诊断
盲读先跑完、记下结果，再诊断：`answer_props.py 答案.SLDPRT --step` 导出 STEP，用 CadQuery 列出答案的每个面（类型、面积、包围盒），和自己的模型逐面比。面的类型（圆柱还是球）、包围盒（某个面从哪到哪）能直接说明错在哪。找到原因后写清楚"从图上本来该怎么看出来"。

### R25. 体积对了不等于对
镜像、键槽转 90°、孔在前面还是后面，体积都一样。非对称零件建完请用户在 SolidWorks 里对照图纸看一眼，特别是剖面。
