## 5. 找图清单（J 去找，Claude 跑，对答案）

**规则**
- 每题要两样东西：**图纸** + **标准答案模型**（.SLDPRT 或 .STEP 都行）。没有模型的图纸也收，但只能人工看对错。
- 放法：`tests/drawings/编号_名字/`，里面放 `drawing.*` 和 `answer.*`。文件名随意，Claude 会认。
- 每题尽量换一样东西：换格式、换标准、换视图、换特征。不要连着找同一类零件。
- 难的、怪的、Claude 可能做不出来的，反而最有价值。做不出来就记进 reading-rules.md / dev/DEVELOPING.md 或"不支持"。

**最省事的来源**
- McMaster-Carr：零件页右侧 CAD 下载，同一个零件给 2D（DWG / DXF / PDF）和 3D（STEP / SLDPRT），英寸美标。
- MISUMI / 米思米中国：CAD 下载，公制，JIS / GB 风格，需注册。
- TraceParts、3D ContentCentral：标准件和厂家件，图纸 + 模型。
- CSWA / CSWP 练习题、SolidWorks 练习图纸 100 例：图纸 + 答案体积（有体积就能对答案）。
- 自己的课程作业、capstone 零件、co-op 图纸：自己有 .SLDPRT，出图最准。
- 机械制图习题集拍照：测扫描件和手机照片，答案自己按图建一个。

## 6. 合成图纸（dev/tools/make_test_drawing.py）

用零件表自动生成带标准答案的图纸：三视图（隐藏线算法）+ 尺寸标注 + 标题栏，输出 DXF / PDF / PNG / 模拟扫描件。标准、单位、投影法可选。用来批量测读图准确率。

| 零件表 | GB | ASME 英寸 | 读图结果 |
|---|---|---|---|
运行：`python dev/tools/make_test_drawing.py --batch`，输出到 tests/synthetic/。每套图有 DXF、带文字 PDF、无文字 PDF、PNG、模拟扫描件，Windows 装了 CAD 还有 DWG。
